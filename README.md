## 🚀 Overview

FinGuard AI is an intelligent cybersecurity platform that helps users identify phishing attempts, scams, and fraudulent content before they become victims.

The application leverages modern AI models to analyze multiple communication channels and provides an easy-to-understand risk score with detailed explanations.
