# 🛡️ FinGuard AI

AI-powered cybersecurity platform that detects phishing, scam, and fraudulent messages using AI.

## Features

- 🤖 AI Scam Detection
- 📩 SMS Analysis
- 📧 Email Analysis
- 💬 WhatsApp Message Analysis
- 🔗 URL Extraction
- 📊 Risk Score Meter
- 📜 Scan History
- 📈 Dashboard Analytics
- 🔐 Secure Authentication
- 🌙 Modern Dark UI

## Tech Stack

### Frontend
- React
- TypeScript
- Vite
- Tailwind CSS
- Framer Motion

### Backend
- FastAPI
- Python
- Gemini AI
- SQLite/PostgreSQL
